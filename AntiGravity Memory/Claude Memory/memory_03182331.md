## 全域架構原則（已確認，勿再修改）

### COM / 執行緒規則
- 所有 Outlook COM 呼叫必須在 UI 執行緒（STA）
- 不可用 Task.Run 包住 COM 物件
- 用 `Await Task.Yield()` 讓 UI 不凍結，不切換執行緒
- `Task.WhenAll` 只有跨 PST 才真正有效（同一 PST 鎖競爭反而慢）
- **重要**：所有 Catch 要寫 `System.Exception`（因 Imports Outlook 導致命名空間衝突）

### Outlook Namespace 衝突
- `Imports Microsoft.Office.Interop.Outlook` 會讓 `View`、`Exception` 等名稱衝突
- ListView 的 `View` 屬性必須寫完整名稱：`System.Windows.Forms.View.Details`
- Catch 必須寫 `System.Exception` 而非 `Exception`

### Cache 設計（已確定，不改）
```vb
Private Shared ReadOnly mailCountCache As New ConcurrentDictionary(Of Outlook.Folder, Integer)
Private Shared ReadOnly folderCountCache As New ConcurrentDictionary(Of Outlook.Folder, Integer)
Private Shared ReadOnly folderSizeCache As New ConcurrentDictionary(Of Outlook.Folder, Long)
Private Shared ReadOnly folderTreeCache As New ConcurrentDictionary(Of Outlook.Folder, List(Of Outlook.Folder))
```

### Bug A 修正（2026-03-18，本次最重要的修正）
**問題**：首次切到 Tab2 時，SimTree2 游標無法停在預設收件匣。

**根因**：`ExpandTreeToDefaultInbox(treeview As TreeView)` 參數是 compile-time 型別 `TreeView`，其中的：
```vb
treeview.SelectedNode = node
```
呼叫的是**原生 TreeView.SelectedNode setter**（`Shadows` 沒有多型，不是 `Overrides`），完全繞過 SimTree 的 Shadows property。原生 setter 觸發 `OnBeforeSelect` → SimTree 裡 `e.Cancel = True` → 選取被取消 → `_selectedNodes` 永遠是空的。

**修正**：在 `ExpandTreeToDefaultInbox` 裡用 `TypeOf` 判斷型別，SimTree 走 `AddSelectedNode` + `FireAfterSelect`：
```vb
If TypeOf treeview Is SimTree Then
    Dim st As SimTree = DirectCast(treeview, SimTree)
    st.AddSelectedNode(node)   ' 直接更新 _selectedNodes + 高亮
    st.FireAfterSelect(node)   ' 手動觸發 AfterSelect 讓統計跑起來
ElseIf TypeOf treeview Is TreeView Then
    treeview.SelectedNode = node  ' 原生 TreeView 正常賦值
End If
node.EnsureVisible()
treeview.Focus() : treeview.Refresh() : Await Task.Yield : Exit Sub
```

同時：`FireAfterSelect` 在 SimTree.vb 改成 **Public**（原本是 Private），讓 Form1 可以呼叫。

**Tab2 初始化 Case 也已簡化**（移除 TreeView2 相關初始化，直接用 SimTree2）：

## SimTree 控制項（SimTree.vb，487行，已完成）

### 關鍵設計
- `Shadows SelectedNode`：**`Shadows` 沒有多型**，透過 `TreeView` 型別變數呼叫會走原生 setter，繞過 SimTree 邏輯。外部要正確設選取只能用 `AddSelectedNode` 或明確 `DirectCast` 到 SimTree。
- `OnBeforeSelect`：永遠 `e.Cancel = True`（阻止原生選取），這是 `treeview.SelectedNode = node` 對 SimTree 無效的直接原因。
- `OnGotFocus`：`_selectedNodes.Count = 0` 時自動選 `TopNode`（供鍵盤 Tab 導覽用）
- `FireAfterSelect`：改成 **Public**，讓 Form1 的 `ExpandTreeToDefaultInbox` 可以手動觸發

### Public 方法
- `AddSelectedNode(node)` — 更新 `_selectedNodes` + 高亮，不觸發 AfterSelect
- `FireAfterSelect(node)` — 手動觸發 AfterSelect（改 Public 後供 Form1 呼叫）
- `ClearSelectedNodes()` — 清除所有選取
- `SetSelectedNode(node)` — 等同 SelectedNode = node
