## 全域架構原則（已確認，勿再修改）

### COM / 執行緒規則
- 所有 Outlook COM 呼叫必須在 UI 執行緒（STA）
- 不可用 Task.Run 包住 COM 物件
- **UI 回應/ESC 中斷**：一律用 `Await Task.Delay(1)`，不用 `Task.Yield()`
  - `Task.Yield()` 只是把 continuation 貼回 queue 尾端，queue 積滿時 ESC/STOP 排不進來
  - `Task.Delay(1)` 用系統 Timer，這 1ms 內 message pump 優先處理鍵盤/滑鼠事件
- `Task.WhenAll` 跨 PST 有效；同 PST 內按 StoreID 分組，組間 WhenAll，組內 sequential
- 所有 `Catch` 要寫 `System.Exception`（`Imports Outlook` 導致命名空間衝突）
- `Imports Microsoft.Office.Interop.Outlook` 讓 `View`、`Exception` 等名稱衝突
  - ListView.View 屬性必須寫 `System.Windows.Forms.View.Details`

### VB.NET 陷阱（重要）
- `If intValue Mod N Then` 在整數不為零時為 True — 邏輯完全反了
- **正確寫法**：`If intValue Mod N = 0 Then`
- 本次在 Tab2 line 1589、Tab3 line 2284 都有此 bug，已全部修正

### Cache 設計（已確定，不改）

### ListView1 進入子資料夾（本次修正）
`ListView1_EnterSelectedFolder` 改用 `SendMessage(TVM_SELECTITEM)` 繞過 WinForms setter 的 EnsureVisible 路徑（原本 `TreeView1.SelectedNode = foundNode` 會觸發 Win32 TVM_ENSUREVISIBLE 沿祖先鏈展開所有節點，每個都觸發 BeforeExpand → LoadSubFolderToTreeView）：

```vb
Private Const TVM_SELECTITEM As Integer = &H110B
Private Const TVGN_CARET As Integer = &H9

Private Sub ListView1_EnterSelectedFolder(selectedItem As ListViewItem)
    If TreeView1.SelectedNode Is Nothing Then Return
    TreeView1.SelectedNode.Expand()   ' 載入真實子節點（若只有 ":::" 佔位）
    Dim subject As String = selectedItem.SubItems(0).Text.Replace(" - ", "")
    Dim foundNode As TreeNode = Nothing
    For Each node As TreeNode In TreeView1.SelectedNode.Nodes
        If node.Text.Replace(" - ", "") = subject Then foundNode = node : Exit For
    Next
    If foundNode Is Nothing Then Return
    ' 確認有子資料夾才進入（GetFolderCount 內有快取，不多餘 COM）
    Dim targetFolder As Outlook.Folder = TryCast(foundNode.Tag, Outlook.Folder)
    If targetFolder Is Nothing OrElse GetFolderCount(targetFolder) = 0 Then Return
    foundNode.EnsureVisible()
    SendMessage(TreeView1.Handle, TVM_SELECTITEM, New IntPtr(TVGN_CARET), foundNode.Handle)
    ListView1.Focus()
    If ListView1.Items.Count > 0 Then ListView1.Items(0).Selected = True
End Sub
```

Private Sub Form1_Resize(sender As Object, e As EventArgs) Handles Me.Resize

## 語法簡化原則（本次整理）

VB.NET 三元運算子 `If(cond, A, B)` 兩個分支都會被求值，含 `Await` 的不能用。

已改善的模式：
- `Return If(node Is Nothing, Nothing, node.Tag)` — GetFolderByName
- `distance(i,j) = If(strA(i-1)=strB(j-1), ...)` — Levenshtein
- `If CheckDebug.Checked Then`（移除多餘 `= True`）
- `With DebugForm / With SimTree2 / With _lastHoveredTreeNode` 區塊
- LINQ：`selectedNodes.Select(TryCast).Where(IsNot Nothing).ToList()`
