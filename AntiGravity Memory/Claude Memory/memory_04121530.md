- **環境**：Outlook LTSC 2021（olNotExchange）、本機 PST 檔、VS 2022

### L2.5 快取代理層（Form1_Outlook.vb）
L1/L2 不直接呼叫 L3，全透過 L2.5 proxy：
```vb
GetCachedMailCount(folder)           ' 同步
GetCachedFolderCount(folder)         ' 同步
GetCachedMailCountAllAsync(folder)   ' Async
GetCachedFolderCountAllAsync(folder) ' Async
GetCachedFolderSizeAsync(folder)     ' Async
GetCachedFolderSizeAllAsync(folder)  ' Async
GetCachedAttachMailList(folder, progress) ' Async
GetCachedAttachFilename(mail)        ' 同步
```

### COM / 執行緒規則（永遠不變）
- 所有 Outlook COM 呼叫必須在 UI 執行緒（STA）
- 不可用 `Task.Run` 包住 COM 物件
- 用 `Await Task.Delay(1, cToken)` 讓 UI 不凍結（高頻迴圈）；簡單讓出用 `Await Task.Yield()`
- `System.Exception` 永遠寫全名（避免與 Outlook namespace 衝突）
- `System.Windows.Forms.View.Details` 不可縮寫

### SQLite 快取層（Form1_SQLite2.vb）
五張表：`folder_stats`、`attach_maillist`、`attach_filenames`、`year_counts`、`month_counts`
- 架構：L2.5 proxy 函數內部插入 SQLite 讀寫，L1/L2/L3 完全不知道 SQLite 存在
- DB 檔案：`OLAcache.db`（LocalAppData）
- 快取有效性：EntryID + `PR_LAST_MODIFICATION_TIME` 比對（新增/修改/刪除）
- 月份快取（`month_counts`）在 dirty folder 更新時清 DB，展開年份時 lazy 重算

### 分層架構（最新版）

### 核心成員變數（Tab2，Form1_MainTabs.vb）
```vb
Private _lv2DataYear As ConcurrentDictionary(Of Integer, Integer) = Nothing    ' 年度 session 快取（已合併多資料夾）
Private _lv2DataMonth As ConcurrentDictionary(Of Integer, Integer) = Nothing   ' 月份 session 快取（方案A：單一變數）
Private _tab2MonthViewYear As Integer = 0   ' 目前月份視圖年份 + _lv2DataMonth 的 cache tag（方案A）
Private _tab2IsMonthView As Boolean = False ' 目前是月份視圖還是年度視圖
Private _tab2FolderList As List(Of Outlook.Folder) = Nothing   ' 目前選取的資料夾清單（BFS 展開後）
Private _tab2SelectSeq As Integer = 0       ' 快速點選防護序號
```

### 關鍵設計決策（2026-04-12）

**`GoToYearView()`（不需 cToken）**
- `_tab2IsMonthView = False`，`_tab2MonthViewYear` 刻意不 reset（讓 `_lv2DataMonth` 快取跨 back-and-forth 繼續有效）
- `Await Task.Yield()`，純 render from `_lv2DataYear`（不碰 COM / Layer2）
- 還原游標到進入前的年份（`FindListViewItemByYear(yearToRestore)`）

**`GoToMonthView(selectedYear, cToken)`（方案A）**
- 命中條件：`_lv2DataMonth IsNot Nothing AndAlso _tab2MonthViewYear = selectedYear`
- 命中：純 render（不碰計算層），瞬間
- 未命中：`Await CollectMonthCounts(selectedYear, cToken)` → 存入 `_lv2DataMonth` + `_tab2MonthViewYear = selectedYear` → render

**`CollectMonthCounts(year, cToken)`**
- 遍歷 `_tab2FolderList`，對每個資料夾呼叫 `GetMonthCountsForYear`（自帶 `_monthCountsCache` + DB + COM 三層）
- 合併結果，回報進度，不碰 UI render

**`ListView2_MouseDoubleClick`** 現在只有 ~12 行，委派給 `GoToYearView()` / `GoToMonthView()`

**`Form1.vb HandleListViewKeyPress`** 也呼叫相同的 `GoToYearView()` / `GoToMonthView()`（2026/04/12 一起更新，消除重複）

### PST Folder Size 結論（已確認）

## Tab3 附件搜尋（穩定，v3 Pipeline）

### 架構（Button3_Click 管線）
```
Step 1. 前置驗證（大小參數合法性）
Step 2. CollectUniqueFolderList（BFS + 去重）
Step 3. GetCachedAttachMailList（L2.5 → DB → L3）
Step 4. FilterBySize（記憶體 LINQ）
Step 5. FilterByAttachDetailsAsync（Phase2，附件細節過濾）
Step 6. ShowResultTab3（虛擬模式 ListView3）
```

### 已確認死路（勿再嘗試）
- DASL/Restrict 無法篩附件檔名（PST 無索引）
- `AdvancedSearch` 在 LTSC 失敗（HResult=0x8007064F）
- `SetColumns` 加 `PR_ATTACH_LONG_FILENAME` → NullReference（附件是子物件）
- `GetTable + GetArray()` 無法取附件檔名

### ListView3 虛擬模式
- `ListView3.VirtualMode = True`，資料存在 `_lv3Data As List(Of MailItemInfo)`
- 排序直接對 `_lv3Data` 做 LINQ，5 萬筆 ~10-30ms
