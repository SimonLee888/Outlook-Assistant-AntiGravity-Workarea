  - `SplitContainer5.Panel2Collapsed = False`（原 Designer 設 True）

  - 舊版 `TreeView5.Visible = True` + `TabPage5.Controls.Add(ListView5)` 寫法已移除
- `Form1.vb` `Form1_Shown()`：Tab5 載入改為 `LoadStoreToTreeView(_pstStoreList, SimTree5)` + `ExpandTvToDefaultInbox(SimTree5)`

#### 2. 搜尋範圍由 SimTree5 選取的資料夾決定
- 舊版：`For Each store In _pstStoreList` 掃全部 PST
- 新版：`GetUniqueFolderList(selectedNodes, includeSub:=True, cToken)` 取代，與 Tab3/Tab4 路徑一致
- 若 `SimTree5.SelectedNodes.Count = 0`，顯示提示訊息並 Return（不再 fallback 掃全部）

#### 3. Fuzzy 相似度改用 JaccardSimilarity
- 舊版：`CalculateSimilarity` (Levenshtein O(n×m))
- 新版：`JaccardSimilarity` (字元集 Jaccard O(n+m)，速度快得多)
  - `JaccardSimilarity` 已定義在 `Form1_MainTabs.vb` Tab4 輔助函數區，同 Partial Class 可直接呼叫
- Fuzzy 門檻從 0.8 調整為 0.6（Jaccard 字元集比對比 Levenshtein 更寬鬆，門檻需調低）
- Fuzzy 模式仍保留前段的「cleanSubj|size」hashKey 預分組，Jaccard 做二次過濾

#### 4. ListView5 加入「相似度」欄
- 欄位順序：主旨 / 郵件大小 / 收到日期 / 寄件者 / 群組 / **相似度** / EntryID（隱藏）
- Exact 模式顯示 100%；Fuzzy 模式顯示實際 Jaccard 百分比
- `CalculateSimilarity` / `LevenshteinDistance` 函數保留在 ■99 舊版備用區，未刪除

## 架構重點（不變部分）

### SimTree 類別
- 類別名稱：`SimTree`（Form1_SimTree.vb，Inherits TreeView）
- Form1 宣告：`Private WithEvents SimTree1/2/3/4 As New SimTree`，SimTree5 改為動態建立

### 狀態列控制項
- `ProgressBar1`（300px）、`ProgressBar2`（480px）— 類型是 `ToolStripStatusLabel`

### ESC 中斷機制
- `_cts As CancellationTokenSource`，`OkayNowYouHaveToken()` 取得新 Token
- `SmartThrottle(sw, cToken, ThrottleFreq.Hii)` 統一節流讓出

### COM / 執行緒規則（永遠不變）
- 所有 Outlook COM 呼叫必須在 UI 執行緒（STA）
- 不可用 `Task.Run` 包住 COM 物件
- `System.Exception` 永遠寫全名（避免與 Outlook namespace 衝突）

### SQLite 快取層（Form1_SQLite2.vb）
六張表：`folder_stats`、`attach_maillist`、`basic_maillist`、`attach_filenames`、`year_counts`、`month_counts`
