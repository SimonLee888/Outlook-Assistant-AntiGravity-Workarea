# Debug 訊息呈現與配對邏輯優化總結

本次優化旨在利用已修復的「呼叫者偵測」功能，減少重複資訊，並確保非同步作業的「開始/結束」配對更加精準穩定。

## 變更項目

### 1. 訊息精簡重構 [MODIFY] `Form1.vb` (Tab2 區域)
針對 Tab2 的統計核心邏輯（多年度、月份統計），我們將 `Dbg` 呼叫進行了大規模清理：
- **移除冗餘**：不再手動在訊息中加入 `ComputeYearCounts()` 等函數名，這部分已由系統自動在 `Calling Method` 欄位補齊。
- **重點呈現**：訊息現在直接顯示您關心的數據細節。
  - *開始*：僅顯示「開始」並附帶核心參數（如：`目標資料夾數: 12`）。
  - *結束*：顯示「結束」並附帶結果摘要（如：`年份: 5 | 郵件總計: 1,200`）。

### 2. 跨狀態配對強化 [MODIFY] `DebugForm.RemoveBeginEnd`
為了解決「開始」與「結束」訊息中參數不同導致配對失敗的問題：
- **參數忽略機制**：系統在「提取比對核心 (Key)」時，會自動剔除結尾的括號區塊 `(...)`。
- **效果**：這確保了不論括號內的細節如何變化，系統都能準確識別並連接同一組開發階段，進而穩定地自動計算出**該次作業的總耗時**。

## 視覺效果對比

> [!TIP]
> **新版呈現 (範例)**：
> `01 開始 Form1.ComputeYearCounts (目標資料夾數: 12)`
> `... (中間的其他資訊)`
> `05 結束 Form1.ComputeYearCounts (共 5 個年份 | 郵件總計: 1,200)`
> 
> 在此情況下，系統仍會自動將 01 與 05 配對，並精準算出這 5 個資料夾總共花費了多少毫秒。
