# Tab4 分欄互動行為優化紀錄

本次優化聚焦於 Tab4 三欄式佈局的動態行為，讓整體操作更具智慧感且節省空間。

## 變更內容

### 📐 擴展權重優化 (Form1.vb)

-   **FixedPanel 設定**：我們將內層分欄 (`scnrTab4Results`) 的 `FixedPanel` 屬性設為 `Panel1` (系列主題主題)。
-   **成果**：現在不管是手動雙擊縮放，或是調整視窗大小，**中間欄位都會保持固定寬度，而最右側的「郵件列表」則會獲得所有新增的空間**。這確保了在大螢幕下你能看到最完整的郵件內容。

### 🤖 自動化動作 (Form1_MainTabs.vb)

1.  **搜尋自動縮合**：
    *   在點擊「搜尋系列郵件」時，系統會自動檢查左側目錄樹是否佔據空間。
    *   若寬度 > 20px，系統會將原寬度記錄在 `Tag` 中，並自動縮合至 **10px**。
    *   **效益**：掃描結果一產出，左側目錄樹即自動「讓位」，提供最大的系列追蹤視野。

2.  **ESC 自動恢復**：
    *   在搜尋結果頁面按下 **ESC** 清除資料後，系統會自動檢查側邊欄狀態。
    *   若處於縮合狀態，會自動從 `Tag` 讀取原寬度並**彈回原位**。
    *   **效益**：重置頁面後，目錄樹自動滑回，方便你立刻選取下一個掃描目標。

## 驗證結果

- [x] **雙擊縮放測試**：雙擊外層分隔線，中間主題欄寬度不變，右側列表正確擴展至全屏。
- [x] **搜尋流程測試**：點擊搜尋，左側 `SimTree4` 順滑切換至 10px 邊界模式。
- [x] **重置流程測試**：按下 ESC，搜尋結果消失，左側 `SimTree4` 自動寬度回復且獲得 Focus。

> [!TIP]
> 這些微小的互動優化能讓 Tab4 呈現出「任務導向」的介面感：搜尋時專注於結果，重置時專注於選取。
