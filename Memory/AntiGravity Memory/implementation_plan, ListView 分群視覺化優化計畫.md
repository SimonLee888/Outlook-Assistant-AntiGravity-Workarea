# ListView 分群視覺化優化計畫

根據您對 `ListView4` 分群顯示的喜愛，我們計劃將此高度實用且美觀的特性推廣到程式的其他部分。

## 分群建議與效果評估

### A. lvwDebug (除錯視窗) - [優先推薦]
- **目標**：提升 Log 易讀性，防止訊息洗版。
- **改動**：按 `DebugForm` 解析出的 `callingMethod` (例如 `Form1.ComputeFolderSize`) 進行分群。
- **效果**：訊息流將按執行函數歸類，您可以摺疊掉正常的函數 Log，專注於出錯的區塊。

### B. ListView2 (日期統計) - [提升互動感]
- **目標**：從「頁面切換」轉向「專業報表」。
- **改動**：按「年份」建立 `ListViewGroup`。
- **效果**：不再需要雙擊進入/退出月份。所有數據在一張大表中展開，並可按年份摺疊。這與 Excel 報表感更契合。

### C. ListView1 (資料夾統計) - [視覺統一]
- **目標**：取代現有的自訂繪製標題，回歸 Windows 原生風格。
- **改動**：按「PST 原始檔案 (Store)」分群。
- **效果**：如果您同時掛載了多個信箱，列表會清晰按信箱名稱分區，比起現在用「藍色底色列」分區會顯得更高級。

### D. ListView3 (附件搜尋) - [條件式實作]
- **目標**：按空間位置歸類搜尋結果。
- **改動**：按「母資料夾」分群。
- **注意**：這需要將 `VirtualMode` 改為傳統模式。若搜尋結果量在 5000 封內，效能差異微小；若結果過巨，則不建議。

## 預計實作步驟 (若您批准方案 A/B)

### Phase 1: lvwDebug (除錯視窗)
1. **修改 `DebugForm.vb`**:
    - 在 `Timer_Tick` 批次寫入時，維護一個 `Dictionary(Of String, ListViewGroup)`。
    - 根據 Caller 建立/獲取群組，並將 `lvi.Group` 指向對應群組。

### Phase 2: ListView2 (日期統計)
1. **修改 `Form1_MainTabs.vb`**:
    - 重構 `RenderLvYearView`，改為一次載入所有年份與月份。
    - 按年份建立群組，月份為清單項。
