# ListView4 內文相似度百分比計算功能實作紀錄

## 修改內容總覽
本次修改為 Tab4 (系列郵件) 增加了動態且高效的內文相似度計算功能，採用了非同步與高度封裝的快取架構。

### 1. 基於「內文」的比對邏輯
不再以「主旨」為對比基準，改為即時從 Outlook 取得郵件的 `Body`。
- **優點**：即使主旨相同（如重複的主旨），也能準確區分內容相似度。
- **實作**：新增 `GetMailBodyByEntryID` 輔助函式，支援 `MailItem` 與 `PostItem`。

### 2. 非同步與背景計算 (UI 流暢優化)
為了防止大內文計算導致 UI 凍結，採用了全非同步架構：
```vb
' 在背景執行緒跑相似度計算
Dim sim As Double = Await Task.Run(Function() CalculateSimilarity(baseBody, targetBody))
```
這保證了使用者在選取郵件時，介面依然可以操作，百分比會逐一顯示。

### 3. 高度封裝的 Static 快取
為了節省記憶體並遵循職責分離原則，快取機制被封裝在事件處理器內部：
- **Static bodyCache**：局部快取，僅在 `Lv4_SelectedIndexChanged` 內可見，減少全域變數污染。
- **_lv4ResetBodyCache 旗標**：當執行新搜尋 (`FillLv4`) 時，會觸發此旗標，通知事件函式在下一次執行時清空其內部的 `Static` 快取。

## 驗證結果
- [x] **流暢度**：快速連續點選不同郵件，UI 毫無卡頓感。
- [x] **準確性**：相似度百分比現在反映的是真實內容的差異。
- [x] **安全性**：加入了類型檢查與 Try-Catch，避免因讀取損毀郵件或特殊類型導致程式崩潰。
