# 實作搜尋框 (txtDebug) 關鍵字歷史回溯 (Walkthrough)

## 變更摘要
我已為 `DebugForm` 的搜尋框 (`txtDebug`) 實作了歷史紀錄回溯功能。現在您可以像在終端機 (Terminal) 一樣，使用鍵盤「上/下」鍵來導覽過去搜尋過的關鍵字。

### 01. 成員變數定義
新增了專屬於除錯視窗的歷史紀錄變數，避免與 `Form1` 衝突。
- `_historyDebug`: 存放過去的搜尋字串（限額 50 筆）。
- `_historyIndex`: 追蹤目前的歷史位置。
- `_tempInput`: 當您從目前輸入處按下「上」鍵時，會自動幫您存下原本打到一半的內容，方便您按「下」鍵再切換回來。

### 02. 事件攔截
在 `DebugForm_Shown` 連結了 `txtDebug.KeyDown` 事件，並實作了 `txtDebug_KeyDown` 處理程序。
- **Enter**: 觸發 `AddToHistoryDebug()` 將目前的內容存入歷史紀錄（會自動去除前後空白並過濾連續重複項）。
- **Up (向上鍵)**: 向上回溯更舊的紀錄。
- **Down (向下鍵)**: 向下導覽至較新的紀錄，直到回到原本正在輸入的內容。

### 03. 邏輯實作 (輔助函數)
新增了以下三個關鍵函數於輔助函數區塊：
- `txtDebug_KeyDown`
- `AddToHistoryDebug`
- `NavigateHistoryDebug`

> [!TIP]
> **使用小技巧**：
> 當您回退到歷史紀錄並修改它後按下 `Enter`，修改後的內容也會作為新的一筆歷史存入，方便下次繼續回溯！
