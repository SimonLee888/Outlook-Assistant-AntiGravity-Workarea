## 1. 變更總覽

### `Form1_ComL3.vb` (底層資料掃描控制)
*   **`GetFolderCountAll`**：將 `Parallel.ForEach` 中的防護從單純的 `<變數> Mod 10` 升級為精確的 `Stopwatch` 100ms 實體節流，避免平行展開極大資料夾樹時造成的 UI 假死。
*   **`GetFolderSize`**：補足了 `GetArray(1000)` 大量批次讀取時的內部進度回報，因為部分單一資料夾可能蘊含超過數萬封郵件。

### `Form1_Main.vb` (UI 與流程控制)
*   **Tab 3 (附件搜尋)**：
    *   Phase 1 (`ScanFolderWithAttachment`): 在讀取資料夾郵件時導入了 100ms 進度更新。

*   **Tab 4 (系列郵件)**：
    *   `Button4_Click` 的搜尋資料夾流程導入了 `IProgress`。
    *   `TreeView4` 建立數十至數百組系列郵件節點前，追加了 100ms 防卡頓更新。
*   **Tab 5 (重複郵件)**：
