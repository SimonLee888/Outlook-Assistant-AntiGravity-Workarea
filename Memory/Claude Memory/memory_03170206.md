## 全域架構原則（已確認，勿再修改）

### COM / 執行緒規則
- 所有 Outlook COM 呼叫必須在 UI 執行緒（STA）
- 不可用 Task.Run 包住 COM 物件
- 用 `Await Task.Yield()` 讓 UI 不凍結，不切換執行緒
- `Task.WhenAll` 只有跨 PST 才真正有效（同一 PST 鎖競爭反而慢）
- **重要**：所有 Catch 要寫 `System.Exception`（因 Imports Outlook 導致命名空間衝突）

### Outlook Namespace 衝突
- `Imports Microsoft.Office.Interop.Outlook` 會讓 `View`、`Exception` 等名稱衝突
- ListView 的 `View` 屬性必須寫完整名稱：`System.Windows.Forms.View.Details`
- Catch 必須寫 `System.Exception` 而非 `Exception`

### Cache 設計（已確定，不改）
```vb
Private Shared ReadOnly mailCountCache As New ConcurrentDictionary(Of Outlook.Folder, Integer)
Private Shared ReadOnly folderCountCache As New ConcurrentDictionary(Of Outlook.Folder, Integer)
Private Shared ReadOnly folderSizeCache As New ConcurrentDictionary(Of Outlook.Folder, Long)
Private Shared ReadOnly folderTreeCache As New ConcurrentDictionary(Of Outlook.Folder, List(Of Outlook.Folder))
Private Shared ReadOnly yearCountsCache As New ConcurrentDictionary(Of String, ConcurrentDictionary(Of Integer, Integer))
Private Shared ReadOnly monthCountsCache As New ConcurrentDictionary(Of String, ConcurrentDictionary(Of Integer, Integer))
' Tab3 Phase1 快取（本次新增）
Private _tab3Phase1Cache As New Dictionary(Of String, Tab3FolderCacheEntry)
```

## Tab3 尋找附件（已完成 + 快取）

### 架構：兩階段搜尋
```
Button3_Click
├── Step1: 驗證大小設定
├── Step2: GetTargetFolders() BFS
├── Step3: GetTab3CandidatesFromCacheOrScan() ← Phase1 快取入口（本次新增）
│    └── ScanFolderWithGetTable(_tab3BaseFilter)  無大小篩選的全集
├── Step3b: LINQ 大小過濾（記憶體，不重打 GetTable）
├── Step4: 決定是否需要 Phase2
└── Step5: ShowTab3Results()
```

### Tab3 Phase1 快取設計（本次實作）
```vb
Private Structure Tab3FolderCacheEntry
    Dim Candidates As List(Of AttachCandidateInfo)  ' hasattachment 全集，無大小篩選
    Dim ItemCountWhenCached As Integer               ' 失效偵測用
End Structure
Private _tab3Phase1Cache As New Dictionary(Of String, Tab3FolderCacheEntry)
Private ReadOnly _tab3BaseFilter As String = "@SQL=""urn:schemas:httpmail:hasattachment"" = True"
```
- key = FolderPath 字串
- 失效條件 = `folder.Items.Count` 改變
- 換大小條件 → 直接命中快取，LINQ 過濾，飛快
- 換附件檔名關鍵字 → 仍需 Phase2（`GetItemFromID`），無快取加速

### 已確認死路（勿再嘗試）
- DASL/Restrict 無法篩附件檔名（PST 無索引）
- `AdvancedSearch` 在 LTSC 失敗（HResult=0x8007064F）
- `SetColumns` 加附件屬性導致 Attachments=null
- **D1 測試結論（2026-03-17 確認）**：`PR_ATTACH_LONG_FILENAME (0x3707001F)` 在 PST GetTable 的 `row(...)` 拋 NullReference。`Columns.Add` 成功只是 MAPI schema 層接受，PST message row 不存這個值（附件子物件屬性，非 MailItem 頂層）。Phase2 無法省掉，此路死。

## CacheSniffer（B4 本次實作完成）

```vb
Private _cacheSnifferCts As New System.Threading.CancellationTokenSource

' Form1_Load 末尾（Form1_Load 需標記 Async）：
Await Task.Delay(1000)  ' 等 Form1_Load 完全結束
CacheSnifferAsync(_cacheSnifferCts.Token)

' Form1_FormClosing 頭部：
_cacheSnifferCts.Cancel()
```

### 設計
- BFS 廣度優先，淺層資料夾先完成
- 每個資料夾依序預熱 Tab1（mailCount + folderCount）、Tab2（yearCounts）、Tab3（_tab3Phase1Cache）
- 每完成一個資料夾固定等 1 秒（duty cycle，讓 Outlook 保持回應）
- CancellationToken 控制，FormClosing 時取消
- 停用方式：把 `CacheSnifferAsync(...)` 那行 comment 掉，一行搞定

## Hover 邏輯（C3 本次完成）

```vb
' HandleTreeViewMouseMoveEvent 最終版（2026-03-17）
' 還原：SimTree 選取節點根據 Focused 還原正確選取色，其他用 Color.Empty
' 套用：SimTree 選取節點 skipHover，其他套淡灰色
If _lastHoveredTreeNode IsNot Nothing Then
    Dim sim As SimTree = TryCast(treeView, SimTree)
    If sim IsNot Nothing AndAlso sim.SelectedNodes.Contains(_lastHoveredTreeNode) Then
        _lastHoveredTreeNode.BackColor = If(sim.Focused, SystemColors.Highlight, Color.FromArgb(240, 240, 240))
        _lastHoveredTreeNode.ForeColor = If(sim.Focused, SystemColors.HighlightText, SystemColors.InactiveCaptionText)
    Else
        _lastHoveredTreeNode.BackColor = Color.Empty
        _lastHoveredTreeNode.ForeColor = Color.Empty
    End If
End If
If node IsNot Nothing Then
    Dim skipHover As Boolean = TypeOf treeView Is SimTree AndAlso
        CType(treeView, SimTree).SelectedNodes.Contains(node)
    If Not skipHover Then
        node.BackColor = Color.FromArgb(240, 240, 240)
        node.ForeColor = SystemColors.InactiveCaptionText
    End If
End If
_lastHoveredTreeNode = node
```
