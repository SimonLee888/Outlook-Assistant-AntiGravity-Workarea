## 關鍵設計決策（本次確認）

1. **`_cancelRequested` 布林保留**：宣告不刪，因為 SQLite2.vb 仍在讀取，Parallel.ForEach lambda 也需要它。ESC Handler 繼續設 `_cts.Cancel()`，但 `_cancelRequested = True` 是否保留由 Simon 確認。

2. **Tab3 Step3 改 Exit For（不 Return）**：保留已收集的 targetMails 讓後續 pipeline 繼續跑，顯示半途結果給使用者看。

3. **ShowYearView 傳 CancellationToken.None**：restore 操作不可取消，這樣消滅了 savedCancel hack。

4. **FetchDirectMailCountsAsync 改 As Task**：回傳值 True/False 從未被使用（`Await FetchDirectMailCountsAsync(...)` 結果丟棄），改成 Sub 語意更清晰。

5. **Parallel.ForEach lambda 保留 `_cancelRequested`**：ct 在 lambda 內用 `ThrowIfCancellationRequested` 的例外會被 Parallel 包成 AggregateException，不如保留布林旗標。
