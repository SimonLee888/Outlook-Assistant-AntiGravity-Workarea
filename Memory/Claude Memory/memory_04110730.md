## 本輪對話的主題：重構取消令牌（CancellationToken）

### 背景
ESC 鍵原先用 `_cancelRequested As Boolean` 全域旗標控制中斷。問題：
- 布林旗標是「事後」輪詢，無法立刻停止 await 中的異步操作
- `_cancelRequested = False` 的 reset 時機散落各處，易出現 savedCancel hack
- 多個 Tab 共用同一個旗標，互相干擾

目標：改用 `_cts As CancellationTokenSource` + `ct.ThrowIfCancellationRequested()`，
ESC → `_cts.Cancel()` → 下一個 yield 點拋 `OperationCanceledException` → 由各入口的 Catch 攔截並清理 UI。

`PrepareNewTaskToken()` 定義在 Form1.vb 行 767：
```vb
Private Function PrepareNewTaskToken() As CancellationToken
    If _cts IsNot Nothing Then
        Try : _cts.Cancel() : _cts.Dispose() : Catch : End Try
    _cts = New CancellationTokenSource()
    Return _cts.Token
End Function
```

## 架構原則提醒（不變）

- 所有 COM 呼叫必須在 UI 執行緒（STA），不可 `Task.Run` 包 COM
- `Await Task.Yield()` 讓出執行緒，後面接 `ct.ThrowIfCancellationRequested()`
- `System.Exception` 必須寫全名（Outlook namespace 衝突）
- `System.Windows.Forms.View.Details` 不可縮寫
- Cache key 全部改為 `FolderPath` 字串
- 壓縮 VB.NET 語法（單行 If/Then、冒號分隔）
- 原有 Dbg/中文註解/日期不可丟棄
