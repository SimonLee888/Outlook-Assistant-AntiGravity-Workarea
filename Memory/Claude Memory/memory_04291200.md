### 新增/修改函數清單（Form1_MainTabs.vb）

#### Layer 1 — `Lv4_UpdateSimilarity` (Async Sub)
- 掛載於 `InitTab4UI` 的 `AddHandler ListView4.SelectedIndexChanged`
- Simon 架構為主：
  - `Task.Delay(100)` 避開 Windows 兩次觸發的過渡期
  - `_lv4SimCts` 取消前次未完成任務
  - EntryID 從 `SubItems(5).Text` 讀取（輕量）
  - 先同步標記全列表（基準=「Base」，其他=「...」）
  - 逐封 `Await GetCachedBodyAsync` → `Await Task.Run(JaccardSimilarity)` → 即時更新欄位
  - 比對範圍：**全列表**（不限同組）

#### Layer 2.5 — `GetCachedBodyAsync`
```vb
Private Async Function GetCachedBodyAsync(entryID As String) As Task(Of String)
' ① 快取命中 → 直接回傳（0 COM call）
```

#### Layer 3 — `GetMailBodyL3`

#### 輔助函數 — `NormalizeBody`
```vb
Private Function NormalizeBody(body As String) As String
' 1. 去除 HTML 標籤（<[^>]+>）
' 2. 去除常見 HTML entities（&nbsp; &lt; 等）
' 3. 去除所有空白字元（含全形空白 \u3000、Tab、換行）
' 4. 轉小寫
' 效果：格式不同但內容相同的郵件（HTML vs 純文字）相似度大幅提升
```

#### 輔助函數 — `JaccardSimilarity`
```vb
Private Function JaccardSimilarity(strA As String, strB As String) As Double
' Charles Wu 算法（2006）現代化版，Simon 優化
' HashSet(Of Char) Jaccard：|A∩B| / |A∪B|
' 擴展至全 Unicode 字元集（原版只有中文 U+4E00~U+9FBF）
' Simon 優化：先找較小集合走迴圈，減少一半迭代次數
' 複雜度 O(n+m)，遠優於 Levenshtein O(n×m)
' 包含/被包含的轉寄引用郵件也能得到高相似度
```

## 架構原則（不變）

### COM / 執行緒規則
- 所有 Outlook COM 呼叫必須在 UI 執行緒（STA）
- 不可 Task.Run 包住 COM 物件
- `GetMailBodyL3` 在 UI 執行緒讀 Body，但 `JaccardSimilarity` 計算放入 `Task.Run`
- `_lv4SimCts` 取消機制：游標快速移動時取消前次任務，避免舊結果蓋掉新選取

### Outlook Namespace 衝突
- `System.Exception` 必須寫全名
- `System.Windows.Forms.View.Details` 不可縮寫

### 程式碼風格
- 壓縮 VB.NET 語法（單行 `If/Then`、冒號分隔）
- 詳細中文註解，附日期與作者
- 原有 Dbg/註解不可遺失
