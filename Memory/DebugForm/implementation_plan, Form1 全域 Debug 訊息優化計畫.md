# Form1 全域 Debug 訊息優化計畫

為了讓全程式的除錯訊息與新版 `DebugForm` 的「自動呼叫者偵測」功能完美配合，本計畫將對 `Form1.vb` 全文進行 Dbg 呼叫重構。

## User Review Required

> [!IMPORTANT]
> **全域替換規則**：
> - `Dbg("開始: XXX", detail)` → `Dbg("開始", detail)`
> - `Dbg("結束: XXX", result)` → `Dbg("結束", result)`
> - 如果原本的 `strA` 只包含函數名（例如 `Dbg("MyFunction()", "ok")`），則會優化為 `Dbg("執行", "ok")` 或保留關鍵提示。
> 
> **安全性保證**：
> 由於 `Form1.vb` 接近 4000 行，我將採取「分區段執行」的方式，每完成一個區段都會進行代碼結構檢查，絕對不會漏掉您的任何原始註解。
